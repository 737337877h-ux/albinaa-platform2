# كود تطبيقي التحصيل والعمليات

الكود مشترك، مع فصل هوية التطبيق والتخزين والصلاحيات والتنبيهات:

| التطبيق | الحزمة | الإصدار | رقم البناء |
|---|---|---|---|
| التحصيل | `com.albinaa.collector` | 1.3.72 | 76 |
| العمليات | `com.alraqi.operations` | 1.0.8 | 9 |

اختيار العمليات يتم بتوافق المتغير `ALRAQI_APP=operations` وخاصية Gradle `-PalraqiApp=operations`. الوضع الافتراضي للتحصيل، ولا تُغيّر هذه النسخة أرقام الإصدارات المثبتة. وُحّد رقم حزمة npm الوصفي مع إصدار التحصيل.

## التطوير والفحص

من مجلد `mobile`:

```powershell
npm ci
npm run typecheck
npm run lint -- --max-warnings=0
npm test -- --runInBand
```

لإنشاء مشروع Android من المصدر، شغّل التحضير في وضع التحصيل أولًا:

```powershell
$env:ALRAQI_APP='collector'
npm run android:prepare
npm run android:collector
npm run android:operations
```

تستخدم سكربتات البناء مسارًا قصيرًا على Windows، وتنفذ إعداد المنتج الأصلي، وتعيد قيمة المتغير البيئي السابقة بعد الانتهاء. يمكن تغيير معمارية البناء عبر معامل `Architecture` في السكربت. أُضيف المصدر الأصلي `native/android/StatementSharePackage.kt`، ويسجله سكربت الإعداد بعد Expo prebuild بدل الاعتماد على تعديل يدوي داخل مجلد Android المولّد.

## إعدادات تبقى خارج المستودع

- ملف Firebase الخاص بالتحصيل: `mobile/google-services.json`.
- ملف Firebase الخاص بالعمليات: `mobile/config/operations/google-services.json`.
- ملفات الحسابات الخدمية ومفاتيح توقيع الإصدارات وملفات البيئة الفعلية.
- صور الحسابات المالية، ولقطات الهاتف وملفات تشخيصه، وبياناته المحلية، وملفات APK وAAB، ومجلدا Android وiOS المولّدان.

يعمل فحص المصدر وتصدير JavaScript دون ملفي Firebase. يلزم توفير التسجيل الصحيح لكل حزمة محليًا عند إعداد التنبيهات السحابية؛ لا يُعاد استخدام تسجيل التحصيل للعمليات. تُوفّر مفاتيح التوقيع المعتمدة عبر إعداد البناء الخاص، ولا تُنشأ هوية توقيع بديلة عند تحديث تطبيق مثبت.

صور الحسابات الخاصة مستبعدة من المصدر العام؛ تعرض شاشة اختيار الحساب رمز المحفظة الافتراضي الموجود أصلًا عند غياب الرسم المخصص، مع بقاء الأسماء والأكواد قادمة من الخادم. يمكن إعداد الرسوم المعتمدة محليًا في `request-voucher.tsx` دون نشر صور بيانات الحسابات.

## نطاق التحقق

جرى فحص الأنواع وLint والاختبارات، وتصدير حزمة Android JavaScript لكل منتج، وExpo prebuild، وتحميل إعدادات Gradle لكل منتج. هذا رفع للكود؛ لا ينشر تحديث APK للمستخدمين ولا يثبت إصدارًا على هاتف.
