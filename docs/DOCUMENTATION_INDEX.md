## قواعد حماية التوثيق

- لا تُكتب كلمات المرور أو مفاتيح JWT أو رموز Expo أو بيانات الاتصال الإنتاجية في هذه الملفات.
- لا تُدرج لقطات تعرض أسماء العملاء أو أرقامهم أو أرصدتهم التفصيلية إلا بعد إخفائها.
- التعليمات المكتوبة تصف السلوك الحالي، وأي تغيير وظيفي يجب أن يحدّث الوثيقة المرتبطة به.
- عند كل إصدار: حدّث رقم الإصدار، سجل التغيير، نتائج الفحوص، ورابط ملف APK/AAB.
