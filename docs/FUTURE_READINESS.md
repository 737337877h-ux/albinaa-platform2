# تهيئة قدرات منصة البناء الراقي المستقبلية

هذه الوثيقة تحدد حدود التهيئة الآمنة للرسائل الآلية، والتحليل بالذكاء الاصطناعي، والمخزون. جميع مفاتيح التشغيل الجديدة متوقفة افتراضيًا، ولا تنفذ أي اتصال خارجي حاليًا.

## الرسائل النصية وWhatsApp

الموجود الآن: قوالب قابلة للتعديل، فتح WhatsApp/SMS يدويًا، سجل تواصل، ومشغّل فعلي للتذكيرات الداخلية اليومية للوعود مع منع التكرار. قبل التشغيل التلقائي الخارجي يلزم:

1. اعتماد مزود رسمي وحسابات وقوالب رسائل موثقة.
2. إنشاء صندوق إرسال (outbox) بحالات `pending/sent/failed/cancelled` ومفتاح منع التكرار.
3. حفظ موافقة العميل وقناة التواصل المفضلة وساعات عدم الإزعاج.
4. إعادة المحاولة بحدود واضحة، وتسجيل رد المزود، وإتاحة الإيقاف الفوري.
5. مراجعة بشرية للقالب والمتلقي والمبلغ في المرحلة الأولى.

مفتاح الأمان: `messaging.autoReminders.enabled=false`، والمزود الافتراضي `messaging.provider=none`.

## التحليل بالذكاء الاصطناعي

يبدأ التحليل ببيانات مشتقة ومحدودة: الرصيد، أعمار الدين، انتظام السداد، الوعود، ونتائج المتابعة. لا ترسل أسماء أو أرقام هواتف إلى أي مزود قبل اعتماد سياسة الخصوصية. كل توصية يجب أن تعرض أسبابها ومصدر بياناتها وأن تبقى قرارًا مساعدًا قابلًا للمراجعة، لا قرارًا ماليًا آليًا.

مفتاح الأمان: `ai.analysis.enabled=false`.

## المخزون وقرارات البيع والشراء

الحد الأدنى المطلوب قبل التوصيات:

- دليل أصناف موحد، وحدات وتحويلات، فروع ومستودعات.
- حركات شراء وبيع ومرتجع وتحويل وجرد مع تاريخ وتكلفة وكمية.
- مخزون متاح ومحجوز، حد إعادة الطلب، مدة التوريد، وهامش الربح.
- مؤشرات دوران الصنف، الركود، نفاد المخزون، تغير التكلفة والسعر، والطلب الموسمي.

بعد اكتمال البيانات يمكن اقتراح: إيقاف/تقييد البيع، رفع أو خفض السعر، إيقاف الشراء، أو إعادة التوزيع بين الفروع. الاقتراح يوضح السبب والأثر المتوقع ولا ينفذ تلقائيًا دون صلاحية وموافقة.

مفتاح الأمان: `inventory.integration.enabled=false`.
