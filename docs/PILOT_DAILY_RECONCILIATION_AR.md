## 4. فحوص عدم التكرار

- [ ] لا يوجد رقم إيصال مكرر داخل الفرع.
- [ ] لا يوجد مفتاح مزامنة/idempotency مكرر أدى إلى عمليتين.
- [ ] التحصيل المعكوس محفوظ مع قيده المضاد ولم يُحذف الأصل.
- [ ] المهمة المكتملة لا تظهر ضمن العمل الجاري.
- [ ] الموعد القادم يطابق نتيجة المتابعة المسجلة.

## 5. القرار اليومي

- [ ] **مطابق:** لا يوجد فرق.
- [ ] **مطابق مع فروق مفسرة:** أُرفق التفسير والمستند.
- [ ] **غير مطابق — إيقاف التوسع:** يلزم إصلاح ومراجعة قبل اليوم التالي.
