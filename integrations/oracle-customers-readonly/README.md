# وكيل لقطة عملاء وأرصدة Oracle للقراءة فقط

ينفذ خمس استعلامات ثابتة على `IAS20261` داخل جلسة تبدأ بـ`SET TRANSACTION READ ONLY`. لا يقبل SQL خارجيًا، ولا يحتوي أي أمر كتابة، ولا يحفظ كلمة المرور.

المخرجات: العملاء، عملات العملاء، الأرصدة المجمعة حسب العميل والعملة، المطابقة مع حساب العملاء الرقابي، والإجماليات الرقابية. تحتوي `manifest.json` على عدد الصفوف وبصمة SHA-256 لكل ملف.

يتم فحص اللقطة أولًا دون كتابة:

```powershell
npm run oracle:customers:sync -- --snapshot <snapshot-directory> --organization <organization-uuid>
```

ولا تُحمّل إلى جداول المرآة إلا بإضافة `--apply`. حتى في هذه الحالة تبقى حالة التشغيل `validating`، ولا تُحدّث جداول `customers` أو `customer_balances` ولا توجد آلية نشر في هذه الدفعة.
